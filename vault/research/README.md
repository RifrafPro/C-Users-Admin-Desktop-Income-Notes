# Research Library — organized from Rich's self-sent emails

Everything Rich bookmarked by emailing himself (Jul 17 – Aug 26, 2026, ~275 threads),
sorted into categories so this and future projects can find things fast.

**Source of truth:** `vault/research-email-findings.md` (the chronological catalog).
This folder is the same material re-sorted by TOPIC.

## Folders
- `guides/` — full saved copies of substantive documents (Google Docs, PDFs we extracted)
- `categories/` — one file per topic, each listing the relevant tools/links + verdicts

## Rules
- Every entry keeps its verdict: 🟢 act · 🟡 maybe · 🔴 skip · 📹 needs /watch
- New self-sent finds get added to BOTH the chronological catalog and the right category file
- This lives in the repo → synced to GitHub → clone to any computer to have it locally
