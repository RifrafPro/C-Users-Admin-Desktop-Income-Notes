# S8 — Disposition Under Control-Before-Disclosure (agent: disposition) — STAGE 6

**Sources:** wholesaling.md §Rule · buyers.md · contracts (NCND, Assignment) · Script 09

## Sequence (never out of order)
1. Confirm CONTROL exists: signed PSA/option in the Deal Record. No control → STOP.
2. Build the **blind teaser** from the matched-buyer shortlist (buyer-matcher ranking):
   submarket, lot size, zoning, price band. **NO address, no owner name, no photos that
   geo-locate.**
3. Draft the Buyer Blast (Script 09) with the fee INSIDE the price. [🔒 Rich: "send it"]
4. Interested builder → **NCND first** (SignNow template; $25K liquidated damages, 24-mo)
   OR skip NCND only if assignment is signed against our in-contract position.
5. Address disclosure ONLY after NCND-signed or assignment executed.
6. Assignment of Contract (our template) → deposit non-refundable → fee on settlement statement.
7. Fallback if no matched builder bites in [7-10 days]: widen to Tier 2 list → then MLS
   as-is listing (Fullmer exit) as last resort — flag to Rich for that call.
8. Log outcome per builder in buyers.md (who bit, at what, how fast) — feeds S1 rankings.
