# S5 — Desktop Valuation + MAO (agent: underwriter) — STAGE 3

**Goal:** conservative numbers from the desk, no appraiser. Pessimistic by design —
the delta is the safety margin.
**Source docs:** wholesaling.md §numbers + §Fullmer adoptions · Script 10

## LAND play (our primary)
1. Exit = matched builder's land budget (their buy-box number, S1). If absent:
   Developer max lot $ = finished value − build cost (sqft × $/sqft, lean $325-375 McLean)
   − soft/carry (~10%) − builder profit (~15-20%).
2. Sanity checks: county land assessment · recent SOLD lot/teardown comps (Redfin/Zillow,
   closed only. **Land Insights, verified 10-12:** the extension puts a $/acre badge on **Zillow**
   search cards only; it's broken on Redfin and never shows on detail pages. The data platform
   (Lite) gives **assessor land/improvement value + last sale price/date** per parcel. It does NOT
   give MLS comps: that layer and the Comping Tool need Starter at $47/mo. So sold-dirt comps still
   come from the underwriter agent. See `skill-land-insights.md`) ·
   Langley-cluster band $1.2-1.8M where relevant.
3. **MAO = builder's max lot price − our fee** (fee ~5% of lot price, $37-80K+).
4. Subtract title-cure cost + delinquent taxes (S4) from what we offer the SELLER.

## HOUSE play (secondary screen)
MAO = (ARV × 70%) − repairs − fee. (ARV allowed here only; never on land plays.)

## Fullmer disciplines
- As-is only on distressed: county assessment + sold comps → average → CHOP for safety.
- Target 10-50¢ of as-is value on messy-title deals; walk if thin ("best deal = the one
  I didn't do"). Bigger delta = mistakes survivable.
## Output → Deal Record: GO/NO-GO · MAO · offer-open number · fee target · confidence level.
